Project · 2026 — Present

YorOS

An offline-first AI operating environment being built initially for African education.

RoleFounder / Builder
StatusActive development
FocusLinux · Local AI · Systems

What it is

YorOS explores a computing model where useful AI can run locally instead of depending entirely on permanent cloud access. The first direction is education: combining a Linux-based environment, on-device AI and learning tools into a system designed for practical hardware and constrained connectivity.

The project is intentionally being developed from the systems layer upward rather than as another web chatbot.

Why I’m building it

Cloud AI is powerful, but it assumes reliable connectivity, recurring service access and infrastructure that cannot always be taken for granted. YorOS is my attempt to explore what an AI-native computing environment can look like when offline capability, local control and efficient hardware use are first-class requirements.

Current work

  • Building from a Debian Linux base.
  • Exploring local language-model runtimes for ordinary hardware.
  • Designing the first bootable YorOS prototype.
  • Validating education workflows where offline AI provides meaningful value.

The public page stays deliberately high-level. Low-level implementation details and experimental architecture are kept out of the public portfolio while the project is still being engineered.
