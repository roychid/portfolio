YorShield Security

A defensive cybersecurity project focused on security monitoring, explainable alerts and guided human response.

RoleFounder / Technical Lead
AreaDefensive cybersecurity
Built withFastAPI · PostgreSQL · Docker · Linux

The project

YorShield Security was developed as an AI-assisted cybersecurity monitoring concept. The technical work included security-event collection, controlled infrastructure simulations, structured event storage, explainable alerts and human approval workflows.

The project pushed me deeper into defensive security and the engineering required to move security events from infrastructure into something an analyst can understand and act on.

What I built

  • FastAPI-based security-event collector.
  • PostgreSQL event storage.
  • Versioned security-event contracts.
  • Controlled simulated network infrastructure.
  • Explainable alert and response concepts with human oversight.
  • Docker and Linux-based deployment environment.
